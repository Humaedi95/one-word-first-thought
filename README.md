A tiny Python program that writes exactly one word to `/output/entry.txt`:
**psithurism** — the sound of wind whispering through trees. It is the first
word that came to mind: rare enough to surprise, vivid enough to call up the
sound of leaves moving in the wind, and it sounds like what it means. No
topic, no explanation, no second draft — just the word.
